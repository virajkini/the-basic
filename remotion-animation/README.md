# Remotion Animation - Amgel Jodi App Showcase

A dynamic, professional video showcasing the Amgel Jodi matrimonial app with stunning animations and transitions.

## Features

- 🎬 **4 Distinct Scenes**: Logo reveal, screenshots showcase, features highlight, and final CTA
- ✨ **3D Animations**: Rotating logo, parallax screenshots, floating effects
- 🎨 **Premium Design**: Gradient backgrounds, particle effects, smooth transitions
- 📱 **App Screenshots**: Beautiful carousel with depth and motion
- ❤️ **Feature Highlights**: Smart matching, security, verified profiles
- ⚡ **10 Second Duration**: Perfect for social media and promotional content

## Setup

```bash
npm install
```

## Development

Start the Remotion Studio to preview and edit:

```bash
npm start
```

## Render Video

Build the final video:

```bash
npm run build
```

Output will be in `out/video.mp4`

## Scene Breakdown

1. **Logo Reveal (0-3s)**: Animated logo with 3D rotation and app name
2. **Screenshots Showcase (3-7s)**: 5 app screenshots with staggered entrance and floating animation
3. **Features Highlight (7-9s)**: Key features with icons and text
4. **Final CTA (9-10s)**: Download call-to-action with logo

## Customization

Edit `src/AmgelJodiShowcase.tsx` to customize:
- Scene duration and timing
- Color scheme and gradients
- Animation speeds and effects
- Text content and styling
- Screenshot selection

## Technical Details

- Total duration: 14 seconds (420 frames @ 30fps)
- Resolution: 1080x1920 (9:16 Mobile/Vertical)
- Format: MP4
- Background: Light purple gradient (#ede0fc → #f6effe)
- Fonts: Poppins (headings), Inter (body text)
- Animations: Lottie confetti, 3D transforms, spring physics
